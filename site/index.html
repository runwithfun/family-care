What the starter shows

One sample day for Maya and Aoife

Family Care opens a fictional child profile and a fixed demo day. The current build lists today’s visits and tasks from a shared in-memory care plan—Maya’s well-baby visit, Aoife’s recovery follow-up, and a task to request an immunization copy.

  • Shared demo plan One care plan instance feeds the starter screen with synthetic people and events.
  • Clear ownership Each event belongs to a family member, so “for you” and child visits stay distinct.
  • Sample records nearby The demo data also includes sample visit and immunization notes.

Designed to stay local

The demo runs on the device

The app opens a sample day and runs without a backend, remote model, or analytics service. GitHub Pages hosts this static project site.

  • Synthetic identities, dates, and clinic notes only
  • Shared care-plan model for the demo day
  • Public immunization references stay as external links

Run the starter on a simulator

The shared UI uses Kotlin and Compose Multiplatform. Clone the repository, use JDK 17, and follow the iOS or Android steps in the README.
