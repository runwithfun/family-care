What it is

A day plan for the people you care for

Family Care opens a fictional child profile and a shared family day. Visits keep their booking state; tasks keep their own completion state. Both can point back to the document that started them.

  • Shared plan One in-memory care plan drives the agenda, profile, and calendar views.
  • Clear ownership Each event belongs to a family member, so “for you” and child visits stay distinct.
  • Document lineage Immunizations, visit summaries, and follow-ups remain linked to their source notes.

Designed to stay local

Family data stays on the device

Records, reminders, and Assistant confirmations run without a remote model, analytics service, or backend deployment. GitHub Pages hosts only this static project site.

  • Local reminders and on-device document tools
  • Confirmed proposals write through the same calendar operations
  • Public immunization references stay as links, not uploaded charts
